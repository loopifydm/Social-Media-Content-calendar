# Loopify Social Media Content Calendar

A lightweight social media content planning dashboard for Loopify.

## Features
- Dashboard with total, pending approval, approved and published counts
- Monthly content calendar
- Add, edit and delete content
- Client-wise content management
- Instagram, Facebook and LinkedIn planning
- Content types: Static Post, Carousel, Reel, Story and Video
- Workflow statuses: Idea, Draft, Design, Approval, Approved and Published
- Caption, CTA, creative URL and published post URL
- Search and filters
- Responsive design
- Browser localStorage persistence

## GitHub Pages
Open **Settings → Pages → Deploy from a branch**, select **main** and **/(root)**, then save.

The app is a frontend-only version, so content is stored in the browser using localStorage. For multi-user/client login, approvals and cloud sync, a backend such as Supabase can be added later.
